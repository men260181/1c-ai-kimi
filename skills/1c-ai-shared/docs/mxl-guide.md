# Табличный документ (MXL)

Навыки группы `/mxl-*` позволяют анализировать, создавать и модифицировать макеты табличных документов 1С — основной формат печатных форм в конфигурациях 1С:Предприятия.

## Навыки

| Навык | Параметры | Описание |
|-------|-----------|----------|
| `/skill:1c-ai-kimi:inspect` | `<TemplatePath>` или `<ProcessorName> <TemplateName>` | Анализ структуры: области, параметры, наборы колонок |
| `/skill:1c-ai-kimi:validate` | `<TemplatePath>` или `<ProcessorName> <TemplateName>` | Валидация: индексы, ссылки, границы |
| `/skill:1c-ai-kimi:mxl-expert` | `<JsonPath> <OutputPath>` | Компиляция макета из JSON-определения в Template.xml |
| `/skill:1c-ai-kimi:mxl-expert` | `<TemplatePath> [OutputPath]` | Декомпиляция Template.xml в JSON-определение |

## Сценарии использования

### Создание макета печатной формы с нуля

Вы описываете макет словами или через JSON DSL, Kimi Code компилирует его в Template.xml.

```
> Создай макет накладной М-11: шапка с реквизитами организации и склада,
> таблица с колонками (номер, наименование, единица, количество, цена, сумма),
> итоговая строка, подписи.
```

Kimi Code напишет JSON-определение с областями, параметрами и стилями, вызовет `/skill:1c-ai-kimi:mxl-expert` для генерации XML, затем `/skill:1c-ai-kimi:validate` и `/skill:1c-ai-kimi:inspect` для проверки.

Рабочий цикл:
1. Kimi Code пишет JSON-определение макета
2. `/skill:1c-ai-kimi:mxl-expert` → Template.xml
3. `/skill:1c-ai-kimi:validate` → проверка корректности
4. `/skill:1c-ai-kimi:inspect` → верификация структуры (области, параметры)

### Создание макета по изображению

Если есть скриншот или скан печатной формы, `/skill:1c-ai-kimi:img-grid` поможет точно определить пропорции колонок.

```
> Вот изображение формы М-11. Создай макет по нему.
```

Рабочий цикл:
1. `/skill:1c-ai-kimi:img-grid` → изображение с пронумерованной сеткой
2. Kimi Code считает координаты границ колонок по сетке
3. Объединяет границы всех таблиц → базовая решётка
4. Пишет JSON DSL с пропорциями `"Nx"` и `"page": "A4-landscape"`
5. `/skill:1c-ai-kimi:mxl-expert` автоматически вычисляет абсолютные ширины из пропорций и формата страницы
6. `/skill:1c-ai-kimi:validate` → `/skill:1c-ai-kimi:inspect` → проверка

### Анализ существующего макета

Быстрый обзор структуры макета без чтения тысяч строк XML.

```
> Покажи структуру макета ПФ_MXL_М11
```

Kimi Code вызовет `/skill:1c-ai-kimi:inspect` и выведет области, параметры и наборы колонок. С флагом `-WithText` покажет ещё и текстовое содержимое ячеек (заголовки колонок, надписи).

### Модификация существующего макета

Декомпиляция в JSON, правка, компиляция обратно.

```
> Добавь в макет М-11 колонку "Примечание"
```

Kimi Code вызовет `/skill:1c-ai-kimi:mxl-expert` для получения JSON, добавит колонку в определение, вызовет `/skill:1c-ai-kimi:mxl-expert` и `/skill:1c-ai-kimi:validate`.

Рабочий цикл:
1. `/skill:1c-ai-kimi:mxl-expert` → JSON из существующего Template.xml
2. Kimi Code модифицирует JSON (добавляет области, меняет стили, параметры)
3. `/skill:1c-ai-kimi:mxl-expert` → обновлённый Template.xml
4. `/skill:1c-ai-kimi:validate` → проверка

> **Ограничения:** Этот сценарий подразумевает полную перегенерацию макета, а не точечную правку XML. Поэтому diff может показать больше изменений, чем фактическая доработка. Кроме того, DSL пока поддерживает не все конструкции табличного документа — для сложных макетов с рисунками, штрихкодами или нестандартным форматированием часть информации может быть потеряна при round-trip.

### Валидация макета

Проверка структурной корректности после любых изменений.

```
> Проверь макет ПФ_MXL_М11
```

Kimi Code вызовет `/skill:1c-ai-kimi:validate`, который проверит индексы палитр, ссылки на наборы колонок, границы областей и другие структурные зависимости.

### Примеры слеш-команд

```
> /skill:1c-ai-kimi:inspect src/МояОбработка/Templates/ПФ_MXL_Накладная/Ext/Template.xml
> /skill:1c-ai-kimi:inspect МояОбработка ПФ_MXL_Накладная
> /skill:1c-ai-kimi:validate МояОбработка ПФ_MXL_Накладная
> /skill:1c-ai-kimi:mxl-expert макет.json src/МояОбработка/Templates/ПФ_MXL_Накладная/Ext/Template.xml
> /skill:1c-ai-kimi:mxl-expert src/МояОбработка/Templates/ПФ_MXL_Накладная/Ext/Template.xml макет.json
```

## Связь с EPF-навыками

Макет табличного документа — часть обработки. Типичный сценарий создания печатной формы:

1. `/skill:1c-ai-kimi:epf-expert` — создать обработку
2. `/skill:1c-ai-kimi:mxl-expert` — добавить макет SpreadsheetDocument (с именем `ПФ_MXL_...`)
3. `/skill:1c-ai-kimi:mxl-expert` — заполнить макет содержимым из JSON-определения
4. `/skill:1c-ai-kimi:epf-expert` — добавить регистрацию БСП с видом ПечатнаяФорма
5. `/skill:1c-ai-kimi:epf-expert` — добавить команду печати
6. `/skill:1c-ai-kimi:epf-expert` — собрать EPF
