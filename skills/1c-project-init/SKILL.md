# /skill:1c-ai-kimi:1c-project-init — инициализация проекта 1С

Создаёт базовую структуру проекта и помогает подготовить локальные настройки Kimi Code. Навыки установлены на уровне пользователя через плагин Kimi Code, поэтому копировать их в каждый проект не требуется.

## Вход

`$ARGUMENTS` — необязательный путь к проекту. Если аргумент не указан, используется текущий рабочий каталог.

## Порядок работы

### 1. Создать базовую структуру

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "${KIMI_SKILL_DIR}/scripts/init.ps1" -TargetPath "<target>"
```

Скрипт создаёт отсутствующие каталоги `src/`, `ext/`, `dist/`, `openspec/`, `docs/` и служебные каталоги. Существующие файлы не перезаписываются. В `.gitignore` добавляются только отсутствующие правила для временных файлов, снимков экрана и локальных учётных данных.

### 2. Собрать сведения о проекте

Запроси только сведения, которых ещё нет в проекте:

- тип: конфигурация, расширение или оба варианта;
- версия платформы 1С;
- расположение исходников конфигурации и расширений;
- параметры информационной базы, если требуется работа с базой;
- публикация веб-клиента, если требуется браузерное тестирование.

Не запрашивай пароль без необходимости. Не выводи и не записывай учётные данные в журнал.

### 3. Подготовить AGENTS.md по запросу

Если пользователь хочет создать проектные инструкции, используй `${KIMI_SKILL_DIR}/templates/AGENTS.md.template`. Заполни сведения о проекте и запиши результат в `<target>/AGENTS.md`. Существующий файл не перезаписывай без подтверждения.

### 4. Настроить MCP по запросу

Kimi Code использует:

- `<target>/.kimi-code/mcp.json` — серверы текущего проекта;
- `~/.kimi-code/mcp.json` — серверы пользователя.

Для интерактивной настройки рекомендуй `/mcp-config`. Шаблон `${KIMI_SKILL_DIR}/templates/mcp.json.template` содержит пустую корректную конфигурацию. Добавляй только серверы, адреса и команды которых предоставил пользователь или которые подтверждены в проекте.

После изменения MCP-конфигурации требуется новая сессия Kimi Code.

### 5. Подготовить параметры базы по запросу

Шаблон `${KIMI_SKILL_DIR}/templates/v8-project.json.template` можно использовать для создания `<target>/.v8-project.json`. Этот файл может содержать пароль и должен оставаться в `.gitignore`. Не создавай его и не заполняй учётные данные без явного запроса пользователя.

### 6. Продолжить работу профильными навыками

- выгрузка исходников: `/skill:1c-ai-kimi:db-dump-xml`;
- загрузка исходников: `/skill:1c-ai-kimi:db-load-xml`;
- обновление базы: `/skill:1c-ai-kimi:db-update`;
- создание конфигурации: `/skill:1c-ai-kimi:cf-init`;
- создание расширения: `/skill:1c-ai-kimi:cfe-init`;
- проверка структуры: `/skill:1c-ai-kimi:inspect` и `/skill:1c-ai-kimi:validate`.

## Ограничения

Не выполняй автоматически `git init`, коммиты, push, SSH, Docker, развёртывание серверов, публикацию баз или изменение информационной базы. Эти действия требуют отдельного запроса пользователя и конкретных параметров его инфраструктуры.
