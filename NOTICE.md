## Адаптация для Kimi Code

В репозитории `men260181/1c-ai-kimi` выполнены следующие изменения:

- комплект оформлен как устанавливаемый плагин Kimi Code с манифестом `kimi.plugin.json`;
- сохранены 55 навыков, их PowerShell/Python/JavaScript-сценарии и общие справочники;
- команды навыков переведены на синтаксис `/skill:1c-ai-kimi:<имя>`;
- неподдерживаемые поля Claude Code удалены из YAML-заголовков;
- ссылки на сценарии и справочники переведены на `${KIMI_SKILL_DIR}`;
- PowerShell-файлы сохранены в UTF-8 с BOM для корректного разбора Windows PowerShell 5.1;
- запуск PowerShell-сценариев использует `-ExecutionPolicy Bypass` только на уровне отдельного процесса, без изменения системной политики;
- вызовы субагентов адаптированы к инструменту `Agent` Kimi Code;
- `1c-project-init` сделан переносимым: удалены адреса, учётные данные и автоматические операции с инфраструктурой автора исходного проекта;
- добавлены документация по импорту, требования к программному обеспечению и инструкции по настройке зависимостей.
